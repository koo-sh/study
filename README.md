# study

딥러닝 공부 기록입니다. 이론은 「모두를 위한 딥러닝」 시즌1, 실습은 시즌2 PyTorch를 따라갑니다. 최종 목표는 ResNet-18을 직접 구현해 Stanford 40 Actions 분류에서 정확도 70% 이상을 내는 것입니다.

## 진행 현황

| 주차 | 내용 | 폴더 | 상태 |
|---|---|---|---|
| 0 | 파이썬 클래스 + NumPy | [`week0/`](week0/) | 진행 중 |
| 1~2 | 머신러닝 기초 (시즌1 Lec 1~7, 시즌2 Lab 01~07), wandb 시작 | | |
| 3 | 신경망과 학습 기법 (Lec 8~10, Lab 08~09) | | |
| 4 | CNN, ResNet 논문, ResNet-18 직접 구현 | | |
| 5 | Stanford40 분류, 70% 달성 | | |
| 6 | wandb, Grad-CAM 시각적 분석, 정리 | | |
